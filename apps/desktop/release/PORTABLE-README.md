# DeepSeek Harness Desktop — 便携版 (0.1.2-alpha.2)

**文件**：`win-unpacked/` 目录　**平台**：Windows x64　**形态**：免安装

> 这是一个**直接可用的成品**：无需安装 Node.js、无需从源码构建，解压即用。
> 本便携版由本仓库源码打包而来，与安装版（Setup exe）功能完全一致，仅交付方式不同。
> 定制内容与「为什么源码和 exe 并存」详见 [README.md](README.md)。

## 使用

1. 解压 `win-unpacked/` 到任意目录（建议放在非系统盘，或 U 盘、移动硬盘）
2. 进入该目录，双击运行 **`DeepSeek Harness Desktop.exe`**
3. 即开即用，无需安装、无需写注册表

> 便携版适合：不想安装到系统、随身携带、多版本并存测试、内网/离线分发。

## 目录结构

```
win-unpacked/
├── DeepSeek Harness Desktop.exe   # 启动主程序
└── resources/
    ├── app/                       # Electron 壳（含自定义标题栏逻辑）
    ├── dsh/                       # dsh 宿主依赖闭包（含全部插件/修复）
    └── node/                      # 内置 Node 运行时
```

## 本版本特性

- **无边框自定义标题栏**：DeepSeek 鲸鱼 logo + 窗口标题，右上角自绘最小化/最大化/关闭按钮，整条可拖拽，**随皮肤/主题自动变色**
- **鲸鱼应用图标**：窗口、任务栏使用 DeepSeek 鲸鱼图标
- **不弹系统浏览器**：启动只打开桌面窗口（已加 `--no-open`）
- **窗口控制正常**：最小化/最大化/关闭按钮可用（修复 preload 模块格式）
- **内容区无滚动条**：默认页（含设置）直接可见
- **装插件免重启**、**新插件 UI 免刷新**
- **modlens 视觉兼容**：修复 `(modlens vision)` 模型的报错

## 卸载 / 清理

删除整个 `win-unpacked/` 目录即可完全卸载，不留任何系统残留。
（用户数据仍存于 `%APPDATA%\@deepseek-ai\dsh-desktop`，如需一并清理可手动删除该目录。）

## 与安装版的区别

|  | 便携版 | 安装版 |
|---|---|---|
| 安装 | 免安装，解压即用 | NSIS 安装器 |
| 注册表写入 | 无 | 创建快捷方式 |
| 快捷方式 | 无（手动创建） | 桌面 + 开始菜单 |
| 卸载 | 删目录即可 | 控制面板卸载 |
